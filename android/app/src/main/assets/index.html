Blockys Móvil

Compañera de Blockys para tu teléfono

Instalar Blockys en la PC

El launcher corre en Windows 10 u 11, de 64 y 32 bits, con un solo setup.

Abrir la descarga

Jugar Minecraft Java en Android

Minecraft Java no trae launcher para Android. La forma establecida de jugarlo es PojavLauncher, que ejecuta Java y el juego en el teléfono.

PojavLauncher en Play Store PojavLauncher en GitHub

Pasar una instancia de Blockys

  1. En Blockys, abrí la instancia y elegí Exportar. Se genera un archivo .zip.
  2. Pasá el .zip al teléfono por cable, nube o Bluetooth.
  3. En PojavLauncher, usá Importar y elegí el .zip.
  4. Iniciá sesión con tu cuenta Microsoft y jugá.

Tus cuentas, instancias y skins quedan en tu PC. Esta app no recolecta datos.
